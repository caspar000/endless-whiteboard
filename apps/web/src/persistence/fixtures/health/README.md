# Health node schema fixture

`v0.1.0-health.json` is a synthetic document snapshot generated by the application store schema with all thirteen health card types. It contains configuration only, under a synthetic dataset identity. `health-snapshot.test.ts` loads it through the current application schema and verifies that every card and its props survive.

Keep this separate from the older shopping fixture: that fixture's tests specifically require legacy item and rollup records. Preserve both when adding migrations.
